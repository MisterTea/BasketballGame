# Rim Rumble Game Design Document Template

> Working template for creative direction, production planning, and investment decisions

This document turns a game idea into a fundable production plan. It should make the player experience concrete, define what the team will build, show how progress will be proven, and expose the choices that affect cost, schedule, and commercial risk.

# How to use this document

Treat this as the project agreement, not a one-time pitch. Write the shortest answer that lets a reader make a decision. Mark assumptions honestly, attach evidence when it exists, and move detail to an appendix when it obscures the core experience.

## Authoring rules

1.  Complete the Executive brief first. If that page is unclear, the rest of the design is not ready to expand.

2.  State what the player does and feels before describing features, technology, or lore.

3.  Separate committed scope from experiments and future ideas. Every committed feature must appear in the schedule and budget.

4.  Replace opinion with evidence where practical. Use prototypes, playtests, comparable products, cost estimates, or technical tests.

5.  Record decisions and the conditions that would cause the team to revisit them.
